# 最长回文子串

给定一个字符串 `s`，返回其中最长的回文子串。若存在多个长度相同的答案，返回最先出现的那个。

## 解法：中心扩展

对每个可能的回文中心向两侧扩展：

- 奇数长度：中心是单个字符
- 偶数长度：中心是两个相邻字符之间的间隙

时间复杂度 **O(n²)**，空间复杂度 **O(1)**。

## 使用

```bash
python3 solution.py
python3 -m unittest test_solution.py -v
```

## 示例

| 输入 | 输出（之一） |
|------|--------------|
| `babad` | `bab` 或 `aba` |
| `cbbd` | `bb` |
| `a` | `a` |
